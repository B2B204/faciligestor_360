# FaciliGestor360

Sistema de gestão empresarial desenvolvido com React + Vite, utilizando Supabase como backend.

## Requisitos

- Node.js 18+
- Conta no [Supabase](https://supabase.com)

## Instalação

```bash
npm install
```

## Variáveis de ambiente

Crie um arquivo `.env.local` na raiz do projeto:

```
VITE_SUPABASE_URL=https://seu-projeto.supabase.co
VITE_SUPABASE_ANON_KEY=sua-chave-anonima
```

## Executar localmente

```bash
npm run dev
```

## Build de produção

```bash
npm run build
```
